# Welcome to HCL Guard :lock:

### OVERVIEW
HCL Guard is a secure password manager designed to protect sensitive data with advanced encryption and secure communication protocols. It features AES-256-GCM-SIV encryption, mTLS, HTTPS, RBAC, key rotation, comprehensive APIs, audit logs, soft delete and restore, and a user-friendly React.js interface. It is dockerized for easy deployment and includes a Python SDK for seamless integration. Built with FastAPI and Uvicorn, HCL Guard enhances security, boosts developer productivity, and supports enterprise-scale workloads.HCL Guard, a robust and secure password management solution, is engineered to safeguard sensitive data by utilizing state-of-the-art encryption algorithms and stringent communication protocols.
